# AWS Community Companion — Expo MVP

A year-round companion for AWS User Groups and AWS Community Days. The initial design follows the visual identity of the Canadian AWS Day city sites: **cream `#FFF9EF`, forest green `#073B29`, orange `#FF7900`, Nunito-like rounded typography and colorful Vancouver/Toronto/Victoria scenery**.

## What's working in this MVP

- Five tabs: **Home, Discover, Events, Connect, Passport**.
- Switch your home community (Vancouver, Toronto or Victoria), follow more than one community, and browse their events.
- Event detail screens and saved events.
- Editable contact card, **offline QR vCard** and native share sheet.
- Personal, self-reported attendance stamps and simple passport achievements.
- Preferences, saved events, profile and passport persisted on-device with AsyncStorage.
- Optional **read-only static JSON feed** with offline cache and bundled fallback.
- Android, iOS and web through Expo Router. No owned backend, account system, tracking pixels or central attendee database.

**The bundled event catalogue is demo data, not real event announcements.** No real date, RSVPs or venue has been invented. Each event explicitly says when details are not announced.

## Run locally

Use Node.js 22.13+ and the current Expo toolchain.

```bash
npm install
npx expo install --fix
npx expo start
```

Scan the displayed QR code using **Expo Go** on Android, or run:

```bash
npm run web
npm run android
npm run typecheck
```

For iOS Simulator, macOS and Xcode are required. Expo Go compatibility follows the Expo SDK release and currently installed client.

If you want to avoid using cloud services entirely, the sample data loads without a network connection after the bundle is installed. An optional static feed only requires fetching the publicly hosted JSON file.

## Connect a static event feed

Create a `community-feed.json` file based on the `src/data/sample.ts` schema or `examples/community-feed.json` and host it on any public static site such as GitHub Pages.

Create `.env.local`:

```env
EXPO_PUBLIC_COMMUNITY_FEED_URL=https://YOUR-STATIC-HOST/community-feed.json
```

Expo inlines this **public** URL at bundle time. No secret/API key should ever go in a `EXPO_PUBLIC_` environment variable.

The app fetches the feed on startup, validates basic shape, caches a copy on-device and falls back to the cache when offline. When no feed URL is configured it uses bundled sample data. For a production launch, add stricter schema validation and feed-integrity controls.

### Public data model

- `communities`: `id`, `city`, `country`, `region`, `label`, `tagline`, `website`, `color`
- `events`: `id`, `communityId`, `kind` (`meetup`, `community-day`, `workshop`), `title`, `summary`, `dateISO` (ISO string or null), `dateLabel`, `venue`, optional `venueNote`, `registrationUrl` (URL or null)
- `version: 1`, `updatedAt`: ISO date

Content can eventually be generated by each user group from their own GitHub repository or event provider, then included in a validated global index via a free GitHub Actions job. Registration, payments and attendee check-in should remain with existing event services.

## Web export and hosting

```bash
npm run export:web
```

This outputs static files to `dist/`. The project uses `web.output = single` (SPA). It can be hosted without a Node backend on static hosting that rewrites requests to `index.html`. When using GitHub Pages, configure correct deployment base path or use a dedicated custom domain, and add a 404 fallback if deep links require it. No deployment has been performed by this deliverable.

## Important scope boundaries

- The QR feature **displays a vCard** for another phone to scan; it does not yet scan other users' QR cards.
- Passport stamps are self-reported, **not** proof of registration or checked-in attendance.
- There is no live event sync, push-notification server, shared user accounts, organizer editor or automatic cross-device data sync yet.
- Only a handful of initial pilot communities are represented in demo data. Additional countries are a feed/configuration expansion, not separate app installs.
- **Branding:** name and package identifiers are provisional. Obtain the appropriate AWS trademark/brand permissions before public distribution. This code does not bundle official AWS logos.

## Project layout

```

src/components/      Shared UI, original offline city artwork, cards
src/context/         Local preferences and catalogue state
src/data/sample.ts   Explicitly labeled pilot/demo content
src/types/           Event, community and profile contracts
src/utils/           Static feed/cache and vCard encoding
assets/              App icons and splash art
examples/            Example organizer-maintained static feed
```
